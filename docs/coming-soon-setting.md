# 発売日時の指定（COMING SOON SETTING）設定メモ

発売前の商品をサイトに表示したまま、発売日時まで購入できないようにするためのアプリ。

- アプリ：COMING SOON SETTING（https://apps.shopify.com/coming-soon-setting ）
- 料金：月額 4.99 ドルから、7 日間の無料体験あり（掲載時点。最新はアプリのページで確認）

## 設定時に確認すること

1. 無料体験の間に、発売前の商品で次を確認する
   - 商品ページのカートボタンが押せないか（隠れているか）
   - **カートや購入手続きに進めないか**（ボタンを隠すだけだと別の経路から買えることがある）
   - 発売時刻になると自動で買えるようになるか
2. トップの「オンラインショップ」セクション（テーマ独自の商品カード `snippets/b-product-card.liquid`）で、
   「近日発売」などの表示が出るか。出ない場合はテーマ側で対応する
3. 商品一覧（コレクションページ）・検索結果での表示
4. 念のため、発売までは在庫を 0 にしておく運用と組み合わせる（「在庫切れでも販売を続ける」はオフ）
5. アプリのボタンや文言がブランドの色・日本語になっているか
